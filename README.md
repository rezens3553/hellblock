# Hellblock: Один блок, который тебя ест (Fabric 1.21.11)

Ты стоишь на одном блоке посреди пустоты и ломаешь его ради ресурсов. Но блок - это печать, под которой заперт Сатана.
Каждый сломанный блок ослабляет печать: блок трескается, ад просачивается, появляется демон, а в финале игра крашится.

## Что внутри

- **Карта «Один блок»**: пресет мира `Hellblock: Один блок` (пустота + блок на `0 64 0`). Выбирается на экране создания мира кнопкой типа мира.
- **Блок-печать** с 5 стадиями и своими анимированными текстурами: трава, трещины, кровоточащий незерак, обсидиан с рунами, живой глаз.
- **Лут по стадиям** (дерево/еда -> руды -> незер -> редкое). Достаточно, чтобы реально пройти игру (есть Ender Pearl, Blaze Rod, рамки портала Края, незерит).
- **Скверна** (счётчик сломанных блоков): 0 / 40 / 120 / 250 / 400 -> стадии 0-4.
- **Красный оверлей и виньетка**, пульсирующие как сердцебиение.
- **Шёпот** в экшн-баре, жуткие звуки, шаги и скрип двери за спиной, фейковый чат «<Сатана> твой_ник».
- **Архидемон** (стадия 3+): неуязвимый, проходит сквозь стены, **замирает, когда ты на него смотришь**, подкрадывается, когда отвернулся, делает шаг к тебе за каждый сломанный блок, гасит факелы/фонари/костры в радиусе 6 блоков.
- **Финал**: демон касается тебя -> экран чернеет, крик, затем нативное окно ОС с сообщением, игра убивается.

## Сборка

Нужна **Java 21** (JDK) и интернет.

```
./gradlew build          # Windows: gradlew.bat build
```

Готовый мод: `build/libs/hellblock-1.0.0+1.21.11.jar`. Положи в `mods/` вместе с **Fabric API 0.141.3+1.21.11** и Fabric Loader 0.18.4+.

Запуск прямо из проекта для теста: `./gradlew runClient`.

Если сборка упадёт с ошибкой компиляции, скопируй ошибку целиком и пришли мне, поправлю (код писался без возможности прогнать компилятор против Minecraft 1.21.11).

## Как играть и снимать

1. Создай мир -> тип мира **Hellblock: Один блок** -> Выживание. **Не Peaceful** (демон там удаляется).
2. Появишься на блоке. Если мир обычный, а не пустота: команда `/hell init`.
3. Ломай блок.

### Команды для записи

| Команда | Что делает |
|---|---|
| `/hell phase 0..4` | перепрыгнуть в нужную стадию |
| `/hell count <n>` | выставить число сломанных блоков |
| `/hell demon` | вызвать демона (в 48 блоках) |
| `/hell finale` | запустить финал сразу |
| `/hell reset` | сбросить в 0 |
| `/hell init` | поставить блок и телепортироваться к нему |

## Конфиг `config/hellblock.json`

Создаётся при первом запуске. Здесь все пороги стадий, скорость демона, шанс мобов, тексты шёпота, фейкового чата и **финального сообщения**.

Важное поле: `deleteWorldOnFinale`.
- `false` (по умолчанию): мир остаётся целым, откатывается на стадию 2. Можно переснимать финал.
- `true`: после краша папка мира **реально удаляется**. Необратимо. Делай копию мира перед съёмкой.

## Текстуры

Все нарисованы скриптом `tools/generate_textures.py` (нужен Pillow: `pip install pillow`). Правишь цвета/узоры, запускаешь, получаешь новые PNG.
Демон: `textures/entity/archdemon.png` (128x128, развёртка как у игрока + рога + крылья).

## Известные ограничения

- Небо и туман не перекрашиваются (в 1.21.11 они стали атрибутами среды). Вместо этого экранный оверлей + эффект «Тьма».
- Звуки только ванильные (Warden, Enderman, Ghast и т.д.), своих .ogg нет.
- Демон парит и проходит сквозь блоки намеренно: на пустом острове ему негде ходить.
